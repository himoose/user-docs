# Versus Pages (SEO programático)

!!! note "Este recurso fica no aplicativo web antigo"
    Conforme o Hi, Moose vira um produto centrado no desktop, a maior parte dos recursos migrou para o aplicativo para desktop. **As versus pages são um dos dois recursos que permanecem no aplicativo web antigo** (`app.himoose.com`); o outro é o [Topical Authority Builder](topical-authority.md). Se você usa o aplicativo para desktop em um plano pago, peça as versus pages ao Moose no chat ou use a ação **Criar versus pages em escala**; o aplicativo web abre com a sua conta já conectada, sem um login separado.

    As versus pages exigem um plano pago.

## Para que serve

Gerar páginas de comparação («X vs Y») em escala, ou seja, SEO programático para buscas comparativas de alta intenção, sem escrever nem atualizar cada página à mão.

Você define os critérios de comparação uma vez, acrescenta seus concorrentes, e o Hi, Moose gera conteúdo original com sua voz da marca, elementos visuais com sua identidade e dados estruturados para cada combinação, posicionando sua marca como a alternativa recomendada dentro do conteúdo (sem que sua marca apareça na URL nem no título da página).

## Como funciona

1. **Defina seu esquema**: as categorias e características que quer comparar (preços, integrações, suporte, por exemplo).
2. **Acrescente concorrentes**: nome, descrição, logotipos e valores para cada característica definida.
3. **Acrescente sua marca**: seus próprios dados, usados para posicionar sua marca dentro do conteúdo comparativo gerado.
4. Siga as demais etapas do assistente para gerar conteúdo, elementos visuais e dados estruturados de cada combinação com a concorrência.
5. **Exporte**: baixe em CSV ou envie direto para o Webflow CMS, se estiver conectado.

## Requisitos

- Pelo menos 2 concorrentes para comparar.
- Uma chave de API do Webflow, se quiser publicar direto no Webflow em vez de exportar em CSV.

## A IA é opcional

Você pode gerar o conteúdo com IA como ponto de partida ou escrever cada comparação manualmente. Nos dois casos o Hi, Moose cuida da lógica de combinação, da geração de imagens e da exportação para o CMS.
