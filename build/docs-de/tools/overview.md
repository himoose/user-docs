# Das Tools-Menü

## Wofür das gut ist

Das **Tools**-Menü in der oberen Leiste ist der schnellste Weg, eine bestimmte Aufgabe zu starten. Öffnen Sie es, suchen Sie oder wählen Sie ein Werkzeug, und Hi, Moose öffnet das passende Formular, statt Sie Ihr Anliegen im Chat beschreiben zu lassen.

Mit **Eingabe** starten Sie das hervorgehobene Werkzeug, mit **Esc** schließen Sie das Menü. Das Suchfeld filtert alle Werkzeuge nach Namen.

## Sie müssen das Menü nicht benutzen

Alles im Tools-Menü lässt sich auch dadurch starten, dass Sie im [Chat](../chat/overview.md) einfach danach fragen. Moose erfasst, worum Sie bitten, und öffnet dasselbe Formular.

Das Menü gibt es, weil Sie manchmal genau wissen, was Sie wollen, und einen Satz zu tippen langsamer ist, als es aus einer Liste zu wählen. Keiner der beiden Wege kann mehr als der andere.

!!! note "Ausdrückliche Anfragen öffnen das Werkzeug, Andeutungen schlagen es nur vor"
    Wenn Sie klar um etwas bitten („auditiere diese URL"), öffnet Moose dieses Werkzeug direkt. Deutet Ihre Frage es nur an, beantwortet Moose die Frage und bietet das Werkzeug darunter als Vorschlag mit einem Klick an, statt das Gespräch zu kapern.
