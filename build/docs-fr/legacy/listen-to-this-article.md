# Listen to this Article (génération audio)

!!! note "Cette fonctionnalité a rejoint l'application de bureau"
    La génération audio ne fait plus partie de l'ancienne application web. Elle se trouve désormais dans l'application de bureau Hi, Moose, sous **Audio**, avec une délimitation par projet, des statistiques d'écoute et une personnalisation du lecteur que la version web n'avait pas.

Rendez-vous sur :

- **[Vue d'ensemble d'Audio](../audio/overview.md)** : sources, réglages de la conversation, voix et historique.
- **[Lecteur et intégration](../audio/player-and-embed.md)** : thème, disposition, code d'intégration et attribution d'agence.
- **[Statistiques d'écoute](../audio/analytics.md)** : lectures, taux de complétion et entonnoir d'engagement.

Les épisodes générés dans l'ancienne application web ne sont pas affectés. Les intégrations déjà en place sur votre site continuent de fonctionner.
